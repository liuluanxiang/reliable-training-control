# reliable-training-control
Reliability-aware training-time control for non-convex deep learning using PAC-Bayes generalization signals and primal-dual optimality indicators.

This repository implements the reliability-aware training-time control framework proposed in Chapter 4 of my PhD research.

The framework integrates PAC-Bayesian generalization signals with primal-dual optimality indicators to guide training-time decisions in non-convex deep learning, including:

• learning-rate scheduling
• early stopping
• optimization stability monitoring

The goal is to improve the reliability, stability, and generalization performance of stochastic optimization in overparameterized neural networks.
